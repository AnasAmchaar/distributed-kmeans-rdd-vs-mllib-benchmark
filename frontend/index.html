4. Surcoût de Sérialisation Python/RDD vs MLlib DataFrame

Comparaison directe des temps d'exécution totaux et par itération entre les 3 moteurs.

Pourquoi MLlib est 45× à 86× plus rapide : Avec les RDD Python, chaque itération Map + reduceByKey doit sérialiser (Pickle/Py4J) les vecteurs 58D entre la JVM et les processus Python externes. L'API DataFrame MLlib exécute K-Means|| directement en mémoire JVM (Catalyst / Tungsten).
